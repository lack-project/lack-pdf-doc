# AI Usage Info

## Sinn der Library

PHP-8.5-Convenience-Layer über `tecnickcom/tc-lib-pdf`. Generische PDF-Infrastruktur liegt in `Lack\PdfDoc\Core`; konkrete Dokumenttypen besitzen eigene Namespaces, Styles und HTML/CSS-Templates.

## Ressourcen-Sicherheit

tc-lib-pdf erhält keine freigegebenen Hosts oder Dateipfade. Bilder werden ausschließlich unter Aliasnamen als `ImageSource` registriert und vor dem Rendering zu `data:image/...` aufgelöst. Markdown/HTML darf keine direkten Bild-URLs oder Dateipfade enthalten.

`ImageSource::bytes()`, `ImageSource::file()` und `ImageSource::resolver()` beschaffen die Bilddaten außerhalb von tc-lib-pdf. Im Markdown wird nur `image:<alias>` verwendet.

## Dokumenttypen

- `Lack\PdfDoc\Letterhead\LetterheadDocument`: Briefpapier mit Logo-Alias, Adressfenster, Markdown/HTML und Footer-Spalten.
- `Lack\PdfDoc\Letterhead\LetterheadStyle`: konfiguriert Layoutwerte, die vor dem PDF-Rendering in CSS eingesetzt werden.

## Beispiele

- [`examples/letterhead/01-basic.php`](examples/letterhead/01-basic.php) – vollständiger Briefkopf-Ablauf bis zum PDF-String.
- [`examples/letterhead/02-images.php`](examples/letterhead/02-images.php) – Bildaliase aus Datei und externem Resolver.
